## Змінні та типи

- EntityId - тип ID, який може бути string або number.
- BaseProduct - базові дані товару.
- Product - товар із додатковими характеристиками їжі.
- OrderStatus - можливі статуси замовлення.
- DeliveryMethod - спосіб доставки.
- CartItem - товар і його кількість у замовленні.
- TimestampMetadata - дата створення та оновлення.
- Order - повна інформація про замовлення.
- newProduct - приклад піци.
- order - приклад замовлення.
- updatedOrder - замовлення після зміни статусу.
